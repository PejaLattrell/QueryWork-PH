# Project budget

This is a personal project with a zero recurring cost requirement. Apply this constraint to every architecture, tooling, storage, and deployment recommendation.

Prefer tools that can run locally and verified free tiers. Check quotas and billing setup requirements before recommending a hosted service. When recommending a local component, explain any availability limits that matter, such as scheduled runs stopping when the PC is off. Discuss paid options only if the user explicitly asks about them.
